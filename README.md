# Setup

## Create environment

```bash
conda create -n berry-price-tda python=3.11
```

## Activate environment

```bash
conda activate berry-price-tda
```

## Open VSCode

Save the workspace:

```text
File -> Save Workspace As
```

## Select interpreter

In VSCode:

```text
Python: Select Interpreter
```

Select the corresponding environment.

## Install the project

From the project root:

```bash
pip install -e .
```
